# Salvageist — browser prototype

**[Play Salvageist](https://chifunt.github.io/salvageist-web/)**

An endless, single-army survival prototype. Steer your machines, choose your
fights, and reclaim defeated enemy wrecks to grow your swarm.

Use a desktop browser with a keyboard and mouse. Hold **left mouse** to steer
(or WASD); hold **right mouse** or **E** near eligible wrecks to reclaim. Reclaiming
temporarily stops your army. **Escape** pauses. Audio starts after interacting
with the game. The corner button toggles fullscreen.

This repository contains **built game files only**. The Unity development project
and third-party asset packages are not distributed here. This is a prototype;
late-game performance depends on the browser and machine, and mobile is not a
supported target yet.
